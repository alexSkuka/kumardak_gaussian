# Кумардак — 3D-модель

[Открыть 3D-сцену](https://alexskuka.github.io/kumardak_gaussian/)

Единая модель горы и окружения, обученная до 30 000 итераций по снимкам, данным Metashape и выровненным данным рельефа Copernicus. Опубликована лёгкая копия: около 1 млн сплатов, файл модели 15,83 МБ. Небо и солнце процедурные.

Мышь или сенсорный экран управляют камерой. В настройках доступны облёт, свободный полёт и выбор качества отрисовки. Все устройства загружают одну лёгкую модель.

Сайт статический; GitHub Pages публикует корень ветки `master`. Файлы сцены и просмотрщика лежат в `assets/`.
